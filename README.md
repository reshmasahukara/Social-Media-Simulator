# 📱 Social Media Simulator

Social Media Simulator is a console-based social networking application developed using **C++** that simulates the core functionalities of modern social media platforms. The project demonstrates the practical implementation of **Object-Oriented Programming (OOP)** concepts, modular programming, and user interaction through a menu-driven interface.

The simulator allows users to create profiles, make posts, add comments, and interact with a simplified social media feed system, making it an excellent academic and learning project for C++ development.
