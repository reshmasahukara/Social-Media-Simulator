# Social-Media-Simulator

A console-based **Social Media Simulator** developed using **C++** that replicates the core functionalities of modern social networking platforms. This project demonstrates the practical implementation of **Object-Oriented Programming (OOP)** concepts such as classes, objects, encapsulation, inheritance, and modular programming.

---

## Features

- User Profile Management
- Create and View Posts
- Add Comments to Posts
- Interactive Console-Based Interface
- Modular File Structure using Header and Source Files
- OOP-Based Design
- Simple Social Media Feed Simulation

---

## Technologies Used

- **Programming Language:** C++
- **Concepts Implemented:**
  - Classes & Objects
  - Encapsulation
  - Modular Programming
  - File Separation (`.h` and `.cpp`)
  - Dynamic User Interaction

## How to Run the Project

### Compile the Program

```bash
g++ main.cpp User.cpp Post.cpp Comment.cpp -o social
```

### Run the Executable

```bash
./social
```

> For Windows:

```bash
social.exe
```
